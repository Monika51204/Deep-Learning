# reports — TV4 điều phối
- `sections/`: phần nội dung từng thành viên viết, có thể Markdown trước khi tích hợp.
- `figures/`: hình xuất từ script.
- `tables/`: bảng xuất từ log.
- `report.docx` và `report.pdf`: bản cuối.
Bố cục chính theo đề: 1 Giới thiệu; 2 Dữ liệu; 3 Mô hình và cài đặt; 4 Thực nghiệm; 5 Thảo luận; 6 Kết luận, tài liệu tham khảo, phụ lục.
