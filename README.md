# Deep-Learning

## Giới thiệu
Đây là repository ghi lại hoạt động, bài tập cũng như quá trình làm đồ án cuối kì. 
Mục tiêu: quản lý tập trung, dễ dàng theo dõi tiến độ và đóng góp của bản thân.

## Cấu trúc thư mục
```text
├── weekly-assignments/   # Bài tập hàng tuần
│   ├── Tuần 01/
│   ├── Tuần 02/
│   ├── ...
│   └── Tuần 0n/
│
└── final-project/        # Đồ án cuối kỳ
```

## Weekly Assignments (Bài tập hàng tuần)
Mỗi tuần tạo một thư mục mới, upload bài tập nhóm, cá nhân kèm commit message (Bài tập nào? Làm những gì?,...).


## Final Project (Đồ án cuối kỳ)
Dùng để cập nhật tình hình và quá trình làm bài của bản thân, ghi lại những đóng góp trong quá trình làm.
Hiện tại giảng viên chưa giao đề, repo sẽ được bổ sung sau.
